# Changelog

All notable changes to CertForge are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Design specification, progress tracker, and repository scaffolding.
- Go module, certforge command skeleton, Makefile, golangci-lint config, CI workflow, development guide, ADRs 0001 and 0003.
- Bootstrap configuration from CF_* environment variables with KEK from env or file.
- Postgres pool, embedded goose migrations (orgs, sites, users, sessions, role bindings, settings, audit events), sqlc code generation, migrate command.
- Envelope encryption (AES-256-GCM DEK per secret, static KEK wrapper) with a compact blob format.
- Settings store with encrypted secrets, JSON-Schema-validated sections (general, backup), and KEK canary.
- Local admin argon2id passwords, Postgres-backed sessions, CSRF enforcement, and request principal middleware.
- Role-based authorization with org-scoped bindings (authz.Can).
- Append-only, hash-chained audit log with chain verification.
- OpenAPI spec with generated strict server, problem+json errors, Swagger UI at /api/docs, meta schema registry, org listing.
- Local admin login, logout, /auth/me with CSRF token, and schema-driven settings GET/PUT endpoints.
- First-run setup endpoints (status, complete) and the bootstrap-admin command.
- serve and healthcheck commands, /healthz and /readyz (DB and KEK canary), embedded web UI handler with SPA fallback and placeholder page.
- Server container image, compose stack with Postgres 16, test overlay with Pebble and challtestsrv, e2e health test.
- Architecture overview and documentation index.
- Issuance database schema: CAs, ACME accounts, DNS credentials, org issuance defaults, certificates, versions, attempts, manual-dns records.
- Routing challenge provider: per-name verification rules (`*`, `*.zone`, `zone`), first match wins, uncovered names rejected before ordering.
- JSON Schemas for all lego DNS providers, generated from lego's metadata, served under `dnsProviders` in `GET /api/v1/meta/schemas`, and documented in `docs/dns-providers.md`.
- DNS credential handling: schema-validated config, write-only secrets with the `__unchanged__` sentinel, and lego provider construction with an isolated environment.
- manual-dns verification: TXT records shown to the operator, attempt resumes on confirmation, fails after 1 hour without it.
- ACME signer on lego v4 with CA presets (Let's Encrypt, staging, ZeroSSL, Buypass, Google Trust Services, SSL.com, custom), EAB registration and Retry-After capture. Cancelling the issuance context now aborts an in-flight CA call promptly, not just manual-dns waits.
- PEM rendering of cert, chain, fullchain, key and combined parts, with deterministic zip bundles.
- Issuance defaults at global, org and certificate level with per-field source, renewal policy (days or percent), and exponential backoff honouring Retry-After.
- Issuance data layer with org scoping, sealed EAB HMACs, account keys and DNS secrets, and delete protection for referenced CAs, accounts and credentials.
- Issue worker: per-attempt step timeline, sealed certificate versions, next renewal from policy, failure backoff with Retry-After.
- Renewal scheduler: river periodic scan every 5 minutes, one unique issue job per certificate, expiry marking and stale-attempt cleanup.
- Issuance service facade (account registration, certificate create/update with auto-enqueue, DNS credential test) and `serve` wiring: river client started and gracefully stopped alongside the HTTP server, `db.Migrate` now also applies river's schema.
- API: CA presets, CAs with EAB, ACME account registration, org issuance defaults and effective defaults with sources.
- API: DNS provider credentials with write-only secrets, stored-secret names, and a live TXT test.
- API: certificates with multi-SAN and wildcard names, per-name verification rules, renew now, versions, attempts with step timeline, PEM/zip downloads with audited key export, and manual-dns records and confirmation.
- End-to-end issuance test that drives the running compose server through its own HTTP API against Pebble and challtestsrv (issuance, chain, SANs, key type, forced renewal, failure backoff); the e2e server image carries the challtestsrv DNS provider.
- Web UI scaffold: design tokens for light and dark themes, Atkinson Hyperlegible fonts, pre-paint theme selection, and a lint rule that blocks native checkboxes and radio buttons.
- Web UI API client generated from the OpenAPI spec, with CSRF headers, problem+json errors, and a single sign-in redirect on session expiry.
- Web UI sign-in page, first-run setup wizard, and session-expiry redirect that returns to the page you were on.
- Web UI shell: grouped sidebar with icon rail and mobile drawer, user menu with System, Light, and Dark themes.
- Web UI controls: switches with state text, selectable chips, searchable comboboxes, write-only secret fields, copy buttons, and type-to-confirm dialogs.
- Web UI status chips (icon plus word) and the validity bar with renewal window, now notch, and successor ghost.
- Web UI issuers: CA preset cards and custom ACME directories with trust bundle and EAB, and ACME account registration.
- Web UI schema-driven forms: switches, segmented controls, chips, and write-only secrets generated from provider JSON Schemas, and a searchable DNS provider picker.
- Web UI DNS credentials for every lego provider, with forms generated from provider schemas, usage counts, and a zone test.
- Web UI settings: General (base URL, read-only organizations list) and Backup (KEK status from `/readyz`, escrow-confirmed switch) from server schemas, and issuance defaults with Global and Org tabs, per-field inherited-value badges sourced from the effective-defaults endpoint, and override/reset-to-inherited controls reused by the future certificate wizard.
- Web UI certificates list: status and search filters in the URL, removable filter chips, saved views, validity bars, click and shift-click selection, and bulk renew or delete.
- Web UI name entry for new certificates: paste lists, chips grouped by registered domain, wildcard and IP markers, and a drag-to-set common name.
- Web UI verification rules: ordered, draggable rules per name pattern with per-zone credential pre-fill, a coverage panel, and credential creation without leaving the wizard.
- Web UI certificate wizard: four steps with a live summary rail, per-certificate overrides with inherited sources, review, duplicate from an existing certificate, and an edit mode that loads an existing certificate into the same wizard and saves with `PUT` (a name change shows a one-line "will issue a new certificate" notice and reissues; anything else applies at the next renewal).
- Web UI attempt viewer (step timeline, ACME error explanations, searchable raw log) with 2-second polling while an attempt runs, and the manual-dns records card.
- Web UI certificate page: header with validity bar and Renew now, Overview, Versions, Attempts, and Settings tabs, and PEM download with part chips.
- Web UI overview: health strip, needs-attention queue with pinned manual-dns cards and inline Renew now, status filters, 90-day expiry horizon with brushing, upcoming renewals; command palette (Ctrl or Cmd K) and g o, g c, n c shortcuts.

### Changed
- Web UI settings: `SettingsPage.tsx`'s `SECTIONS`/`SectionSlug` moved to a small `sections.ts` so the settings route's `beforeLoad` no longer drags the whole Issuance defaults section (and `tldts`) into the app's main chunk; the build's largest chunk drops from 977 kB to under 400 kB, with no chunk over the 500 kB warning threshold, and `npm run build` now fails if `tldts` reappears in an eagerly-loaded chunk (`web/scripts/check-chunks.mjs`).

### Fixed
- Deleting a CA or ACME account locks the row for the whole count-then-delete in one transaction, so a concurrent `acme_accounts` insert (an actual foreign key) cannot slip a new reference in between the check and the delete.
- Closed the remaining half of that race: writers that store a `caId`/`accountId` reference in jsonb instead of a foreign key (org issuance defaults, the global `issuance_defaults` section) now take a `FOR KEY SHARE` lock on the referenced row before validating and writing, so a CA/account delete's `FOR UPDATE` lock blocks them (and they block it) until one side finishes; a delete's own "is this still referenced" checks now also run inside its own transaction. `PUT /settings/issuance_defaults` validates the global section with the new transactional `(*issuance.Store).ValidateGlobalDefaultsTx` (referenced CA/account/DNS credential rows must exist) and writes it through the same transaction, not just against its JSON Schema.
- A syntactically malformed `caId`/`accountId` in `PUT /settings/issuance_defaults` (the section schema's `format: uuid` is an annotation, not an enforced assertion) now returns 422 like every other invalid value on the section, not 400.
- `NextRenewAt`'s percent-mode renewal calculation no longer overflows for a very large certificate lifetime; a step returning to a non-terminal status no longer keeps a stale `FinishedAt`; a `Timeline` save now runs while the lock is held so concurrent updates can't land out of order; the `issuance_defaults` settings schema now caps `renewPolicy.value` at 99 in percent mode; DNS credential config errors are classified by error type, not by matching substrings; writes to global or org issuance defaults now verify that a referenced CA, ACME account or DNS credential row actually exists, and deleting one now also checks the global defaults section.
- `FinishAttempt` now only closes an attempt still `outcome = 'running'`, so a second finish call (for example a panic recovery racing the worker's normal error path) cannot silently overwrite an already-recorded outcome.
- Final review fixes: published Pebble's e2e management port only (not the ACME port), closed a setup/bootstrap-admin takeover gap (bootstrap-admin now refuses before setup completes; Complete revokes a pre-existing admin's sessions), added resource-exhaustion limits on public auth routes (body size, password length, argon2 concurrency, server timeouts), made the KEK canary write insert-if-absent, made audit-write failures log-and-continue, and corrected several doc inaccuracies.
- Argon2 timing-equalizer hash no longer contends for the argon2 concurrency semaphore, so it cannot be permanently disabled by a saturated first call; the semaphore's release closure now captures the channel it acquired instead of the package variable; the KEK canary write is now insert-or-fill, treating a `crypto.canary` row with a NULL secret as absent; `bootstrap-admin` docs and help text now say "reset (after setup)" instead of "create or reset".
- Deleting a DNS credential now locks the row for the whole count-then-delete in one transaction, and writers that store a `dnsCredentialId` reference in a rule (org and global issuance defaults) take a `FOR KEY SHARE` lock on it before validating and writing, closing the same race already closed for CAs and accounts; `validateDefaultsTx`'s rule check previously validated referenced DNS credentials through the pool while the rest of the transaction held its locks through a different connection, so the rule check took no lock at all (unlike the CA/account checks beside it) and could not block a concurrent delete — it now runs through the transaction's own queries. `TestDNSCredential` now always runs `CleanUp`, even when `Present` failed partway through, so a failed test never leaves the record behind.
- A DNS provider error could echo a write-only secret back out (raw or URL-query-escaped) through `POST .../dns-credentials/{id}/test`'s response, the issuance worker's attempt log/`lastError`, or the audit log; every such error is now scrubbed (`challenge.Scrub`) before it leaves the provider wrapper, `Build`, or the test endpoint. The test endpoint no longer relies on context cancellation to bound a call lego's own interface can't accept a context for: it now races the call against a timer in a goroutine, answers `{ok:false, error:"timed out"}` promptly, and lets cleanup keep running in the background; it's also gated by a 2-slot semaphore (503 + `Retry-After` beyond that). Config keys ending `_FILE`/`_PATH` (schema `serverPath: true`) are now rejected with 422, since they name a path on the server's own filesystem that the API cannot accept from a caller.
- `challenge.Scrub` redacted config values in cfg's random map iteration order with no length floor, so a short unrelated value (a poll interval, a TTL) could land inside a longer secret first and split it into leftover fragments instead of one clean redaction — reproduced in the majority of runs against a crafted overlap. It now builds the replacement list once, longest value first (ties broken by field name) regardless of map order, always redacts a field the provider schema marks `secret: true` no matter how short, and only redacts a non-secret value at 4+ characters; each value is also matched in its `url.PathEscape`'d and JSON-string-escaped forms, not just raw and `url.QueryEscape`'d. `Build` now also refuses a `serverPath` value (not just `SplitConfig`), so a credential stored before that check existed still can't be built. The test endpoint's concurrency slot is now released inside the background goroutine once the provider call actually finishes, not when the handler returns on timeout, so a burst of timed-out callers can't pile up unbounded in-flight provider calls; its audit action is `dns_credential.test`, matching the others. `transip` (whose only lego credential input is a private-key file) is now marked unsupported and rejected with 422 until file-backed credentials arrive in Phase 5, rather than silently accepted and always failing at issuance time; `oraclecloud` gained its previously-undocumented inline `OCI_PRIVKEY` field (lego already reads it via `env.Get`), making it usable at all.
- Phase 1B final-review fix wave: an operator changing a certificate's names while an issuance attempt was in flight could have the edit silently overwritten — `MarkCertificateIssued` now compares the names actually issued against the row's current names in the same query and keeps `next_renew_at` due now instead of the normal renewal date when they differ. `internal/challenge/router.go`'s `PreCheck` now enforces a per-name propagation budget independent of `Router.Timeout`'s single order-wide value, so a `dns-01` name sharing a certificate with a long `manual-dns` wait is no longer polled by lego for just as long as that wait; a CNAME `cnameAliasZone` mismatch now fails the same fast way a manual-dns timeout already did. The built-in `propagationSeconds` default is now unset (provider default) instead of a fixed 120s, so a DNS credential's own `*_PROPAGATION_TIMEOUT` config can take effect. Updating a DNS credential's config now rejects (422) changing a public (connection) setting while leaving a secret `__unchanged__`, closing a path where a stored secret could be silently repointed at a new endpoint; the audit event lists which public keys changed. The issuance worker's panic-recovery path now applies the normal failure backoff instead of only recording the attempt; its in-flight timeline saves during the final commit no longer risk deadlocking the connection pool, and every save now has a 5s bound. `UpdateCA` rejects (409) a `directoryUrl` change while an ACME account is still registered against it. `hyperone` (file-only passport) is now marked unsupported like `transip`; `INFOBLOX_CA_CERTIFICATE` is now marked `serverPath`. The e2e compose build now tags its image separately from the dev image, so a dev `up` can never run the e2e-only provider.
- Web UI shell, fix round 1: the mobile drawer now also closes on any route change (not just a sidebar link's own click handler) and when the viewport widens past the drawer breakpoint, so an org switch, a `g o`/`g c` shortcut, or browser back/forward no longer leaves it open. Global shortcuts no longer fire while focus is inside an open dialog, sheet, popover, or menu, or during IME composition, and Ctrl/Cmd-K only calls `preventDefault` once a command-palette handler is registered. Sidebar active-item highlighting now uses a segment-boundary-aware match instead of a raw prefix check, so "/o/acme/certificates-foo" no longer lights up Certificates and every `/settings/:section` correctly lights up Settings. The org switcher's accessible name now includes the visible org name. An account with no organizations now sees org-scoped nav items disabled with a tooltip and lands on a one-sentence, one-button empty state instead of a broken `/o//overview` link or a crash.
- Web UI certificates list, fix round 1: applying a saved view, going back/forward, or clearing the search chip no longer gets silently reverted 250ms later by a stale debounce. A failed list fetch now shows Retry instead of an empty state, and the first load shows real loading rows (or card skeletons on a phone) instead of a bare paragraph. Bulk renew and delete now keep exactly the certificates that failed selected and name up to 5 of them in a toast, instead of clearing every selected row regardless of outcome; a bulk delete that fails entirely leaves the confirm dialog open with its error instead of closing as if it had succeeded. Also: the status filter has its own "Revoked" segment, the selected-row tint no longer stops at the sticky Name column, the bulk action bar is hidden on a phone, and the delete confirmation title is pluralised correctly.
- Web UI wizard names step, fix round 1: the client's IP check now matches the server's `net.ParseIP` exactly, so an out-of-range or malformed address (a bad octet, too few IPv6 groups, a doubled "::", an IPv6 zone id) no longer classifies as a valid IP and enables Next only to be rejected server-side; a wildcard on a registrable "private" domain like `*.github.io` is no longer wrongly marked invalid. The wildcard and IP chip markers now carry an icon and a tooltip (the IP one stating Phase 1 can't validate IP names until HTTP-01 lands) instead of a bare word. Dragging a name onto Common name now announces "Common name" to screen readers instead of a raw element id, and a disabled chip (the common name itself, or an invalid name) is no longer a focusable no-op in the tab order.
- Web UI certificate wizard, fix round 1: the edit-mode reissue notice now compares the ordered `[commonName, ...sans]` list the server actually reissues on (`internal/issuance/store_certs.go`'s `slices.Equal`, after the same lowercase/trim/dedup normalisation), not a name *set* — a common-name-only change (the set is unchanged) now correctly shows the notice, and an untouched edit no longer shows it. A 422 or 500 banner now clears on the next edit or step change, not only on the next submit attempt. `rememberFromRules` no longer runs on every edit-mode save, only create and an edit whose rules actually changed, so saving an unrelated field can no longer overwrite a credential remembered for another certificate's rule in the same zone. An edit-mode save that changed no names now lands on the certificate's Overview tab instead of Attempts, since it queued no new issuance. The summary rail and the Review step's options list now stack below `md` (was `lg`), and the names list wraps long values, so the wizard no longer overflows at 375px.
- Web UI attempts and manual DNS, fix round 1: a step whose message only appeared on a later poll (running turning failed) no longer stays permanently hidden — its visibility now tracks the current step, not just the render it first mounted on. "Copy log" on the raw log viewer, and "Copy all as zone lines" on the manual-dns card, now guard a missing or rejecting Clipboard API instead of throwing or leaving a rejection unhandled, showing the same failure state as `CopyField`. The Attempts tab now shows an error state with Retry on a failed fetch instead of the empty "No attempts yet" state. The manual-dns card now shows a fixed "records expired" message once the deadline has passed instead of a stale "add these before" line, and clears a 409 ("nothing waiting, or the records expired") once a fresh set of records actually arrives instead of leaving it above the new records indefinitely.
- Web UI certificate page, fix round 1: Overview and Settings now share one `EffectiveConfigList` (stacks to one column below `md`) and one `NameChipStatic` instead of two copies of each. The Versions table pins its Serial column so it stays visible while the rest of a row scrolls at 375px, and its empty state now offers a Renew now button. `filenameFrom` takes only the last path segment (guards a smuggled directory or `../` in a Content-Disposition filename), supports an unquoted `filename=`, and falls back to the raw value when `filename*`'s percent-encoding is malformed. Deleting a certificate from its own detail page no longer briefly flashes a 404 before navigating to the list.
